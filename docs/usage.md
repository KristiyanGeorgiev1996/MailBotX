# Usage

Start the bot:

```bash
python main.py
```

# Usage

## Commands available in Telegram

| Command | Description |
|---------|-------------|
| /start  | Start email notifications |
| /stop   | Stop notifications |
| /status | Show bot status |
| /last   | Show last email |
| /stats  | Show email statistics |
| /test   | Send test message |
| /menu   | Show all commands |

The bot checks Gmail every 10 minutes and sends **HTML formatted messages** to Telegram.
